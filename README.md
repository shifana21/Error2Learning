# Error2Learning 💻

### Your Personal Programming Error Notebook

**Error2Learning** is a simple, beginner-friendly web application that helps programmers save coding errors, understand their causes, and store working solutions for future reference. Instead of solving the same programming mistakes repeatedly, developers can build their own searchable knowledge library.

## ✨ Features

- **Save Coding Errors** — Store error titles, messages, causes, and solutions.
- **Multiple Languages** — Organize errors by Python, Java, JavaScript, SQL, and other languages.
- **Search & Filter** — Quickly find saved errors using keywords and language filters.
- **Favorites** — Mark important errors for quick access.
- **Edit & Delete** — Update existing entries or remove errors you no longer need.
- **Copy Solutions** — Copy saved code solutions easily.
- **Dashboard Statistics** — Track saved errors, favorites, and programming languages.
- **Persistent Storage** — Keep saved entries in your browser using LocalStorage.
- **Responsive Design** — Use the application on desktop and mobile screens.

## 📸 How to Use

1. Open the Error2Learning website.
2. Click **Add New Error**.
3. Enter the error title, programming language, error message, and cause.
4. Add the working solution, tags, and notes.
5. Save the entry.
6. Search, filter, edit, or favorite your saved errors whenever needed.

## 💻 Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/shifana21/Error2Learning.git
   ```

2. Open the project folder:

   ```bash
   cd Error2Learning
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

No additional packages or build tools are required.

## 💡 Why Error2Learning?

Programmers often encounter similar errors while learning new languages, developing projects, or practicing coding problems. Error2Learning provides a personal space to document those mistakes and their solutions, helping developers learn from experience and avoid repeating the same errors.
